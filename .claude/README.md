# .claude/ — Session Context

Tracking + handoff files for Claude Code sessions (same convention as IndyPOS and Recorder).

| File | Purpose |
|------|---------|
| `STATUS.md` | Current state, next actions, blockers (~50 lines max). **Read first each session.** |
| `session-log.md` | Recent session history. |
| `session-log-archive.md` | Older sessions (archive when `session-log.md` > ~100 lines). |

Architecture and conventions live in the root `CLAUDE.md`. Planning docs for larger efforts live in `.planning/`.

Update `STATUS.md` and `session-log.md` proactively as work progresses, and refresh `STATUS.md` at session end for a clean handoff.
