# .planning/ — Planning Docs

Design docs, implementation plans, and diagrams for larger efforts (epics/features), mirroring the IndyPOS/Recorder workflow.

Suggested layout when an epic starts:

```
.planning/
  <epic-name>/
    PLAN.md          # goals, scope, task breakdown
    diagrams/        # architecture / flow diagrams
    completed/       # finished epics, kept for historical context
```

Quick status and next actions stay in `.claude/STATUS.md`. Use this folder for the deeper "why" and multi-step plans that outlive a single session.
